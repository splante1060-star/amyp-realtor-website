# Amy Plante Realtor Website

A custom, responsive real estate website designed and developed for Amy Plante Realtor, serving clients across Massachusetts, Rhode Island, and Florida.

**Live Website:** [amyplanterealtor.com](https://www.amyplanterealtor.com/)

---

## About the Project

This project gave me the opportunity to take a website from a blank page to a fully launched digital presence for a real business. I worked directly with my client to understand what she wanted the website to accomplish, how she wanted her business to feel online, and what would make the experience simple and helpful for potential clients.

I designed and developed the website using React and TypeScript, creating its visual direction, page structure, reusable components, responsive layouts, and interactive details.

I owned the entire process—from initial planning and design through development, client feedback, revisions, search optimization, analytics, and launch. The project challenged me to consider how design, development, content, accessibility, search visibility, and user experience work together to support a client’s business goals.

---

## Features

- Responsive design for desktop, tablet, and mobile
- Specialized real estate service pages
- Reusable React components
- Service-specific FAQs and contextual links
- Prefilled email inquiries based on each visitor’s needs
- Property search, home valuation, and consultation resources
- Newsletter subscription
- Client testimonials and featured sales
- Downloadable resources and contact card
- Custom privacy policy and branded 404 page
- Search engine optimization and local business structured data
- Google Analytics 4 conversion tracking
- Google Search Console and XML sitemap integration
- Social sharing metadata

## Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

---

## Deployment

The website is deployed with **Vercel**.

Every push to the main branch automatically triggers a new production deployment.

---

## Design Goals

The website was designed to feel polished, personal, and approachable while clearly communicating Amy’s experience and specialized real estate services.

Key design principles include:

- Clear and supportive messaging
- Elegant typography and visual hierarchy
- Responsive, accessible layouts
- Simple paths to contact Amy
- Helpful content without unnecessary clutter
- Consistent branding across every page
- Search-friendly page structure and content
